Two steps in, the library from step one has a shape: three definitions, two of
them exported, all of their types written down. Bringing that into a file of your
own takes two directives, and they are not the same one written twice.

<Sample
  path="samples/iyi/modules.iyi"
  from="module samples/modules"
  to="using app/formal"
  must="import app/greeter"
/>

`import` names a module and loads it at most once, so the import graph is a DAG
rather than textual inclusion. What it gives you is the module under its
qualified name and nothing more. After that line alone, `polite` is
`App::Greeter.polite` and nothing shorter.

`using` is what shortens it, and you write it. The library does not get to. That
is the whole of R-2b, and it is a smaller idea than it sounds: importing a module
never changes what your unqualified names mean, so no library can capture a name
in your file by adding one to itself.

The selective form on the last line is the interesting one. `app/greeter` and
`app/formal` both export `title`, so taking both whole would make every bare
`title` in the file ambiguous. It takes exactly `address` from the second module
and leaves that module's `title` behind. Not tidiness: a repair.

## Where the ambiguity gets reported

Widen that second `using` to the whole module and nothing happens. Two modules
exporting one name is not a mistake. The error arrives later, at the first bare
`title` you write, because that is the first thing that could mean either.

Then add your own `def title` to the file and it compiles again. A local
definition beats a used one, silently. That silence is deliberate: it is what
stops a library breaking your build by adding an export.

## The reverse mistake

The two directives are separate, so either can be the one you forgot. Write the
`using` and leave out the `import`, and the compiler does not guess which module
you meant:

<Quote id="import_missing" as="diagnostic" />

It names the rule and writes out the line you meant. The rules are new, so the
compiler teaches them at the moment they are broken, which is the only place a
person is actually paying attention.

## Now forget the other one

Do it the other way round. Import the module, and call one of its exported
functions the way every other language would let you.
